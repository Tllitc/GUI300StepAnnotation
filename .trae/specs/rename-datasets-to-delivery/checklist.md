# Checklist

- [x] Excel 读取按列名定位 `平台`、`采集人员`、`文件夹编号`，缺列时给出明确错误
- [x] 平台值 `Windows/windows/安卓/Android/ios/IOS/iOS/Mac/macos` 均可映射到母目录真实平台目录
- [x] 无法识别的平台、缺失源目录、Excel 重复条目、目标编号目录已存在，四类问题都会在复制前中止并给出清单
- [x] 预检失败时目标目录不会产生任何新增文件
- [x] 每个平台独立从 `gui_000001` 开始按 Excel 行序连续编号
- [x] 输出结构为 `目标目录/平台/gui_XXXXXX/`
- [x] 源目录数据保持不变（复制而非移动）
- [x] 数据集内 `<编号>.json` 与 `<编号>_<数字>.png` 前缀全部替换为新编号
- [x] `_coords.json`、`*_draft.json`、`*.bak`、`*.bak_<时间戳>` 及非编号前缀文件均不被复制，输出文件数量等于白名单文件数量
- [x] JSON 内 `screenshot` 等引用同步为新编号，且 JSON 中引用的每个截图文件在输出目录中真实存在
- [x] JSON 的 intent、CoT、actions 等其余内容未被改动
- [x] 目标目录生成 `数据集映射表_<时间戳>.xlsx`，包含序号、平台、采集人员、原文件夹编号、新编号、源目录、输出目录、状态、备注
- [x] 取消或部分失败时映射表仍生成，状态区分成功/失败/未处理
- [x] 界面三个路径选择项可用，Excel 默认预填同目录清单
- [x] 转换在工作线程执行，界面不卡顿，进度与日志可见，可取消
- [x] 参数缺失时提示且不执行转换
- [x] 核心逻辑不依赖 Qt，`pytest datasubtool/tests` 全部通过
- [x] 真实数据小样本联调：源目录未变、目标命名正确、json 引用与图片对应、映射表正确
- [x] 命中平台起始序号按平台分别生效，默认 1，非法值预检中止且不复制
- [x] `_coords.json`、`*_draft.json`、`*.bak`、`*.bak_<时间戳>` 等非数据集文件不被复制，输出文件数量等于白名单文件数量
- [x] 数据集无任何白名单文件时标记失败且不残留空输出目录
