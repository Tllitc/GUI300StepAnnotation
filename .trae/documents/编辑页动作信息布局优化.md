# 编辑页动作信息组件布局优化

## Summary

优化标注编辑页（`StepEditorWidget`）的布局与参数显隐：

1. 将"截图预览在上、动作表单在下"的上下结构改为**左右分栏**（截图预览在左约 65%，动作信息在右约 35%，QSplitter 可拖拽调比例），右栏参数区可滚动；
2. 参数区域重构为**按动作类型精确显隐**（消除脆弱的行索引、去掉空"参数:"行、参数标签按动作语义变化、terminate 显示无参数占位提示）；
3. 截图预览随分栏/窗口尺寸变化**防抖重绘**，始终按区域大小等比缩放，不留灰边、不被截断。

只改 `annotation_editor.py` 一个文件。所有输入控件的对象与属性名保持不变，`get_data()`/`load_data()`/必填校验/截图自动填坐标等数据逻辑零改动，最终 JSON 格式不受影响。

## Proposed Changes

### 1. 重构 `StepEditorWidget.init_ui()`：左右分栏布局（L44–L240）

- 顶层 `layout = QVBoxLayout(self)` 内放一个水平 `QSplitter(Qt.Horizontal)`，命名 `self.editor_splitter`；
- **左栏**：现有的 `preview_group`（QGroupBox "截图预览"），内含 `screenshot_label`：
  - `screenshot_label`：minimumSize 改为 (420, 300)，sizePolicy 设为 Expanding/Expifying 由 splitter 拉伸；保留灰底样式；
  - 左栏容器 `setMinimumWidth(420)`；
- **右栏**：`form_group`（QGroupBox "动作信息"）外套一个 `QScrollArea`（`setWidgetResizable(True)`、水平滚动条始终关闭、垂直滚动条按需），滚动区 `setMinimumWidth(300)`；
- `self.editor_splitter.setSizes([740, 400])`（约 65:35，对应右编辑区 ~1140px 宽），`setStretchFactor(0, 3)`、`setStretchFactor(1, 2)`，使两侧随窗口同比缩放、用户可拖拽覆盖；
- 顶层 layout 边距收紧（与主窗口 `contentsMargins(2,2,2,2)` 风格一致）。

### 2. 参数行去索引化 + 语义化标签

- 删除 `self.params_widget`/`self.params_layout` 这层嵌套与 `addRow("参数:", ...)`，动态参数行**直接加入主动作表单 `form_layout`**；
- 为每个动态行保存 `(label_widget, field_widget)` 引用到 dict，替代魔法数字：
  - `self.row_coord`：标签改为可动态切换的 `self.coord_label`（单坐标动作显示 `"坐标 [x, y]:"`，拖拽时显示 `"起点坐标 [x, y]:"`），字段为现有 coord_layout；
  - `self.row_end_coord`：`"终点坐标 [x, y]:"` + end_coord_layout（不变）；
  - `self.row_text`：标签改为可动态切换的 `self.text_label`，字段为 `text_input`；`text_input.setMaximumHeight(80)`（右栏变窄，给两行以上高度）；
  - `self.row_keys`：标签 `"按键组合（点输入框后按实际按键）:"` + keys_layout；
  - `self.row_scroll`：`"滚动像素:"` + scroll_layout（按钮逻辑不变）；
  - `self.row_wait`：`"等待时间（秒）:"` + wait_time_input；
  - 新增 `self.no_param_label = QLabel("该动作无需填写参数")`（灰色斜体），作为 terminate 专属占位行 `self.row_no_param`；
  - status_combo 隐藏行维持现状（不注册进动态行集合）；
- 新增动作→可见行的显式映射 dict（类常量或方法内字面量）：

  | 动作类型 | 可见动态行 | 文本标签/坐标标签文案 |
  |---|---|---|
  | left_click/double_click/triple_click/right_click/middle_click/mouse_move | coord | 坐标 [x, y]: |
  | left_click_drag | coord + end_coord | 起点坐标 [x, y]: |
  | scroll | coord + scroll | 坐标 [x, y]: |
  | type | text | 输入文本: |
  | open_app | text | 应用名称: |
  | open_url | text | 网址 URL: |
  | answer / answer_terminate | text | 回答内容: |
  | key | keys | — |
  | wait | wait | — |
  | terminate | no_param | — |

- 重写 `on_action_type_changed()`：先隐藏动态行集合中全部行（label+field），再按映射 show 对应行并设置标签文案；滚动测量按钮的显隐逻辑保持现状（仅 scroll 且测量中显示 finish 按钮）；
- 删除 `show_params(indices)` 方法（无外部调用，确认后删除）；
- 隐藏行用 `label.hide()/field.hide()`（QFormLayout 隐藏后整行不占位，空"参数:"行随之消失）。

### 3. 截图预览 resize 防抖重绘

- `StepEditorWidget` 新增信号 `preview_resize_requested = pyqtSignal()` 与实例属性 `self.preview_meta = None`（tuple：`(filename, rect_info, selection_type)`）、`self.preview_resize_timer`（QTimer, singleShot, 250ms，timeout 发信号）；
- 重写 `StepEditorWidget.resizeEvent(event)`：调父类后，若 `self.preview_meta is not None and self.isVisible()`，重启防抖定时器；
- `set_screenshot(pixmap)` 保持现有缩放逻辑不变（新截图即时显示，不依赖 resize）；
- 新增 `set_preview_meta(filename, rect_info, selection_type)` 保存 meta；
- 在 `AnnotationEditor` 侧：
  - `_refresh_step_preview(index)`（L1981）成功设置 pixmap 后调用 `editor.set_preview_meta(...)`；
  - `on_capture_completed`/`on_recapture_completed` 中 `set_screenshot` 之后同样 `set_preview_meta(filename, rect_info, selection_type)`（数据现成）；
  - 新增编辑器创建处（`on_capture_completed` 新建 `StepEditorWidget` 与 `load_from_draft` 重建处）连接 `editor.preview_resize_requested` 到新槽 `_on_editor_preview_resize(editor)`：仅当 `editor is self.steps[self.current_step_index]["editor"]` 时，用 `editor.preview_meta` + `editor.screenshot_label.size()` 调 `build_marked_preview` 重建并 `set_screenshot`（label 尺寸异常时沿用 400×300 兜底）；
  - 300 个隐藏页即便收到布局 resize，槽内当前页判断 + `isVisible()` 双保险保证不产生磁盘 IO 风暴；拖拽 splitter 松手后最多一次重建（250ms 防抖）。

### 4. 不做的事（明确排除）

- 不改任何控件对象的属性名与层级数据接口（`intent_input`/`coord_x_input`/`text_input`/`keys_input_*`/`pixels_input`/`wait_time_input`/`action_type_combo`/`status_combo` 等全部保留）；
- 不改 `get_data()`/`load_data()`/校验规则/draft/JSON 结构；
- 不改截图拉框、滚动测量、按键捕获的交互流程；
- 不改左侧导航栏与外层主窗口布局；
- 不恢复任何常驻全屏 QPixmap（resize 重建只读当前步磁盘文件，读完即释放）。

## Assumptions & Decisions

- 用户已选定**左右分栏**方案（AskUserQuestion，2026-10-24）；初始比例 65:35（sizes [740,400]），可拖拽；
- 参数标签语义化（type/open_app/open_url/answer 区分文案、拖拽区分起点/终点）作为"只显示相关参数"的一部分一并实施；
- terminate 用灰色"该动作无需填写参数"占位，避免右栏大片空白；
- 右栏滚动用 QScrollArea 包裹整个动作信息组；左栏截图不滚动（等比缩放适配）；
- 预览重绘防抖 250ms，重建源统一为磁盘文件（新截图在显示前已落盘，无需在 editor 缓存全屏 QPixmap）。
